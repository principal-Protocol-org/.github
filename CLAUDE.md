# CLAUDE.md

The organization profile of Principal on GitHub: `profile/README.md` is what https://github.com/principal-Protocol-org shows. This repository is public.

- The logos (`profile/logo-light.svg`, `profile/logo-dark.svg`, copies of `org/docs/public/`) are referenced by their `raw.githubusercontent.com` URL on `main` inside a `<picture>`, so GitHub shows the dark one in dark mode.
- `profile/avatar.png` is the organization's picture. GitHub has no API for it: upload it by hand in the organization settings (Profile picture).
- Facts follow the docs (`org/docs`), which follow the code. No grant, SCF or tranche content.
